# Valdi CRM

Учёт клиентов и заказов мебельного производства. Python 3.10+, Flask, SQLite. Без сборки фронта, без внешних JS-библиотек.

## Запуск локально

**Windows:** двойной клик по `start.bat`
**macOS / Linux:** `./start.sh`

Вручную:

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt
python run.py --demo            # с демо-данными
python run.py                   # пустая база
```

Открыть: http://127.0.0.1:5000

- Без `--demo` при первом запуске создаётся `admin` со случайным паролем — пароль выводится в консоль один раз.
- С `--demo` (только в пустую базу): 14 клиентов, ~45 заказов за 6 месяцев и учётки:

| Логин | Пароль | Роль / доступ |
|---|---|---|
| admin | admin12345 | Администратор, всё |
| manager | manager12345 | Руководитель, все разделы |
| sales | sales12345 | Сотрудник: главная, клиенты и заказы (управление) |
| workshop | workshop12345 | Сотрудник: только просмотр заказов |

**Перед боевым запуском смените демо-пароли или начните с пустой базы.**

## Команды

```bash
flask --app valdi create-admin                       # создать admin, пароль сгенерируется
flask --app valdi create-admin --login boss --password 'Secret123'   # или сбросить пароль
flask --app valdi seed-demo --force                  # очистить базу и залить демо
```

## Функции (как в исходной системе)

- **Вход** по логину/паролю, роли: Администратор, Руководитель, Сотрудник.
- **Права по разделам:** главная, клиенты (просмотр/управление), заказы (просмотр/управление), сотрудники. Управление включает просмотр. Администратору открыто всё. Меню и кнопки скрываются по правам, сервер отвечает 403.
- **Главная:** период 7/30/90 дней, год, всё время. Выручка, заказы, средний чек, новые клиенты, в работе, просрочено. Выручка по месяцам, статусы (кольцо, % выполнено), категории мебели, сроки доставки (просрочка и ближайшие 3 дня), последние заказы, лента событий.
- **Заказы:** фильтры по номеру, ФИО, телефону, типу мебели, статусу (+ «в работе», «просроченные»), датам; сортировка по колонкам; пагинация.
- **Новый / изменение заказа:** клиент из базы (живой поиск по ФИО и телефону) или новый клиент прямо в форме; позиции: тип, описание, Ш×В×Г мм, кол-во, цена; итог считается на лету и пересчитывается на сервере; дата доставки, дата создания, статус + комментарий в историю.
- **Карточка заказа:** реквизиты, состав, смена статуса с комментарием, история изменений, удаление.
- **Клиенты:** поиск, карточка с заказами и суммой, создание, изменение, удаление (только без заказов). «Сохранить и создать заказ».
- **Сотрудники:** создание, изменение, отключение, удаление; пароль ≥ 8 символов; логин уникален.

Статусы: Принят → В производстве → Готов → Доставлен, плюс Отменён. «В работе» и просрочка — Принят / В производстве / Готов.

## Безопасность

- Пароли — `werkzeug` (scrypt/pbkdf2), CSRF-токен во всех формах, SQL только с параметрами.
- 5 неудачных входов за 10 минут с одного IP на логин — блок на 10 минут.
- Отключение сотрудника или смена его пароля сразу завершает его сессии.
- Нельзя отключить/удалить себя и последнего администратора; не-администратор не может назначать и менять администраторов.
- Защита от open redirect после входа, заголовки `X-Frame-Options`, `nosniff`, `no-store`.

## Сервер (Ubuntu, VPS)

```bash
sudo adduser --system --group valdi
sudo mkdir -p /opt/valdi-crm && sudo cp -r . /opt/valdi-crm && sudo chown -R valdi:valdi /opt/valdi-crm
cd /opt/valdi-crm
sudo -u valdi python3 -m venv .venv
sudo -u valdi .venv/bin/pip install -r requirements.txt gunicorn
sudo -u valdi .venv/bin/flask --app valdi create-admin

sudo cp deploy/valdi.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now valdi

sudo cp deploy/nginx.conf /etc/nginx/sites-available/valdi
sudo ln -s /etc/nginx/sites-available/valdi /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d crm.example.kz
```

Переменные окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `VALDI_SECRET_KEY` | генерируется в `instance/secret_key` | ключ сессий |
| `VALDI_DB` | `instance/valdi.db` | путь к базе |
| `VALDI_TZ` | `Asia/Almaty` | часовой пояс дат |
| `VALDI_COMPANY` | `Valdi` | название в интерфейсе |
| `VALDI_SECURE_COOKIES` | — | `1` за HTTPS |
| `VALDI_BEHIND_PROXY` | — | `1` за nginx |
| `VALDI_SESSION_HOURS` | `12` | срок сессии |
| `VALDI_HOST` / `VALDI_PORT` | `127.0.0.1` / `5000` | для `run.py` |

**Бэкап:** вся база — один файл.

```bash
sqlite3 /opt/valdi-crm/instance/valdi.db ".backup '/backup/valdi-$(date +%F).db'"
```

## Структура

```
valdi/
  __init__.py      фабрика приложения, фильтры, CLI
  auth.py          вход, роли, права, CSRF, защита от перебора
  db.py, schema.sql
  utils.py         деньги (в тиынах), телефоны, даты, статусы
  demo.py          демо-данные
  views/           dashboard, orders, clients, employees
  templates/       Jinja2
  static/css/app.css, static/js/app.js
run.py             локальный запуск
deploy/            systemd + nginx
```
